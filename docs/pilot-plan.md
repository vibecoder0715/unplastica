# Small pilot plan

Start with a private group of students and a read-only mentor preview. Do not use Greenbits for real prizes until the verification review is complete.

Track, at minimum:

- verified sign-ups and weekly active students;
- proof attempts and approval/rejection counts by habit;
- false approvals and missed valid photos from a separately reviewed sample;
- duplicate-proof flags, model availability, and photo deletion completion;
- student reports about confusing or unfair decisions.

Pause automatic awards if false approvals rise, the score service is unavailable, photo deletion fails, or the model rejects one habit much more often than the others. Keep model version, score, and label with each decision so results can be checked later. Review the pilot after the first 50–100 submissions before inviting more students.
